# Mohammad Nurul Islam — Personal Portfolio

A responsive, cinematic, animated personal portfolio built with plain HTML, CSS and JavaScript. It is designed to publish on GitHub Pages.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

## Personalize before publishing
Open `index.html` and replace:
- `YOUR_EMAIL@example.com` with your professional email address.
- `YOUR_LINKEDIN_URL` with your LinkedIn profile URL.
- Add your approved CV PDF to this folder (for example `Mohammad_Nurul_Islam_CV.pdf`) and add a Download CV link if desired.
- Add a professional photo and any public work samples you have permission to share.

Review the experience section against your latest CV and adjust job titles/dates before making the website public. The portfolio currently describes work areas without inventing exact dates or private contact information.

## Publish using GitHub Pages
1. Sign in to GitHub and create a **new public repository** named `mohammad-nurul-islam-portfolio` (or another name you prefer).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment to finish. GitHub will show your website URL in the Pages section. It usually looks like `https://YOUR-USERNAME.github.io/mohammad-nurul-islam-portfolio/`.

## Files
- `index.html` — portfolio content and structure
- `style.css` — responsive layout, animations and visual styling
- `script.js` — mobile navigation and scroll reveal
